## 💡 Quick Tips

### For Debugging
1. Check browser console for frontend logs
2. Look for `[LiveStreamService]` and `[VideoSDKService]` prefixes
3. Check backend logs for API errors
4. Verify VideoSDK credentials in backend .env

### For Development
1. Always test locally before committing
2. Follow TypeScript strict mode
3. Add proper error handling
4. Update documentation for changes
5. Write meaningful commit messages

### For Testing
1. Test on multiple browsers
2. Test on mobile devices
3. Test all three stream types
4. Test edge cases (no balance, network loss)
5. Document all bugs clearly
